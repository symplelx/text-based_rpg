# 🤝 Jak brać udział w rozwoju projektu (Contributing)

Dzięki za zainteresowanie projektem **Text-based RPG** autorstwa **Symplelx**! Każda pomoc w postaci zgłoszenia błędu, dodania nowej mechaniki czy poprawienia tłumaczenia jest mile widziana.

## 🚀 Jak dodać swoją zmianę?

1. **Sforkuj** to repozytorium.
2. Utwórz swoją gałąź funkcji (`git checkout -b feature/NowaFunkcja`).
3. Zaznacz swoje zmiany (`git commit -m 'Dodano nową funkcję X'`).
4. Wyślij zmiany do swojej gałęzi (`git push origin feature/NowaFunkcja`).
5. Otwórz **Pull Request**.

## 📝 Zasady pisania kodu

- Kod powinieneś pisać w prostym i przejrzystym stylu (zgodnie z PEP 8).
- Wszystkie nazwy zmiennych i funkcji powinny być czytelne.
- Wszystkie nowe teksty w grze dodawaj do słownika `LANG` w pliku `app.py`, aby zachować pełne wsparcie dla wersji polskiej oraz angielskiej!

Masz pytania? Wejdź na [symplelx.pl](https://symplelx.pl).
